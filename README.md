# Chess

A local two-player chess game built with Python's standard library and Tkinter.

## Run

```powershell
python chess_game.py
```

Click a piece, then its destination square. The game supports legal moves,
check and checkmate, stalemate, castling, en passant, promotion choices, and
common automatic draw conditions. Use **New game** to restart.

## Tests

```powershell
python -m unittest
```
